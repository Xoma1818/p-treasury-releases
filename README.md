# Kazna — выпуски для Windows

Kazna — приложение для личных и семейных финансов. Счета, операции, бюджет и отчёты хранятся на вашем компьютере. [Исходный код и документация](https://github.com/Xoma1818/p-treasury) · [Сообщить об ошибке](https://github.com/Xoma1818/p-treasury/issues/new/choose)

## Установить или запустить без установки

Откройте [последний выпуск](https://github.com/Xoma1818/p-treasury-releases/releases/latest) и найдите нужный файл в разделе **Assets**.

- **Установщик:** `Kazna_X.Y.Z_x64-setup.exe`. Скачайте и запустите файл.
- **Переносная версия:** `Kazna_X.Y.Z_x64-portable.zip`. Распакуйте архив и запустите программу из этой папки. Данные хранятся в папке `data` рядом с программой.

## Обновления

Установленная версия проверяет наличие обновлений. Список изменений указан в описании каждой версии. Для переносной версии скачайте новый архив и замените файлы программы, сохранив папку `data`.
