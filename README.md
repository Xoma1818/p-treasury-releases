# P-Treasury — выпуски

Здесь лежат готовые версии **P-Treasury**: программы для личного и семейного бюджета на компьютере (Windows). Счета и операции в нескольких валютах, бюджет на месяц, отчёты и сравнение периодов, займы и долги с графиком платежей, инвестиции, календарь с напоминаниями, сводка в Excel. Данные хранятся только на вашем компьютере, без облака и регистрации.

Исходный код закрыт и в этом репозитории его нет: только выпуски и этот файл.

## Как установить

1. Откройте [последний выпуск](https://github.com/Xoma1818/p-treasury-releases/releases/latest).
2. Скачайте файл `P-Treasury_X.Y.Z_x64-setup.exe` и запустите его. Права администратора не нужны.
3. Windows может показать окно SmartScreen «Система Windows защитила ваш компьютер»: у программы пока нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

**Без установки (например, с флешки):** скачайте `P-Treasury_X.Y.Z_x64-portable.zip`, распакуйте в любую папку и запустите. Данные будут храниться в папке `data` рядом с программой.

## Обновления

Программа сама проверяет этот репозиторий при запуске и предлагает новую версию. Перед обновлением она делает копию ваших данных; счета и операции после обновления остаются на месте. Что нового в каждой версии — в описании выпуска.
